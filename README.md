# NIYAZ Studio — Personal Brand Systems

Статический сайт без сборщика. Подходит для Cloudflare Pages.

## Deploy
1. Загрузите содержимое этой папки в GitHub.
2. В Cloudflare Pages выберите репозиторий.
3. Build command: **None**
4. Build output directory: **/** (корень репозитория)

Можно также использовать Direct Upload и загрузить ZIP.

## Где менять
- `index.html` — весь текст и структура.
- `styles.css` — визуал, адаптив и эффекты.
- `script.js` — анимации, прогресс и форма.
- `assets/` — логотип и изображения.

Форма запроса брифинга открывает почтовый клиент с письмом на `hello@niyaz.studio`. Замените адрес в `index.html` и `script.js` на реальный.
